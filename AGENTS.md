# Workspace Instructions

This workspace's active application lives in `backend/`.

## Routing

- For any task that touches files under `backend/`, first read `backend/AGENTS.md`.
- Treat `backend/AGENTS.md` as the authoritative application instruction file for Laravel work in this repository.

## Project Rules

- Before planning, editing, or answering implementation questions about files in `backend/`, read `backend/.ai/rules/index.md` if it exists.
- Then read every rule file referenced by that index that applies to the files in scope.
- If the task is about Laravel, API, database, validation, authorization, or testing behavior in `backend/`, those `.ai` rules are load-bearing and must be followed.

## Scope

- Do not assume the repository root is the application root.
- Run Laravel, Composer, npm, and test commands from `backend/` unless the task explicitly targets something else.
